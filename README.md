## Héberger sur GitHub Pages
1. Créer un dépôt public sur github.com (ex. `carte-hotel`).
2. « Add file » > « Upload files » : glisser TOUT le contenu du dossier (avec `assets`), puis « Commit changes ».
3. Settings > Pages > Source : « Deploy from a branch », branche `main`, dossier `/ (root)` > Save.
4. Après ~1 minute, le lien est : https://VOTRE-NOM.github.io/carte-hotel/

Astuce : générer un QR code de ce lien pour le poser en chambre.
